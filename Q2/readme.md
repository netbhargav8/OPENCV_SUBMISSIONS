Task 2: Image Blending via Feature Matching

Methodology: Extracted keypoints and binary descriptors across normal_light.jpg and low_light.jpg using an ORB detector. Feature pairings were isolated via a Hamming-distance Brute-Force Matcher with mutual cross-checking. The coordinate vectors of top matches were processed through RANSAC to compute a $3 \times 3$ Homography matrix ($H$). The low-light image was spatially mapped onto the normal frame's coordinate space using cv2.warpPerspective and merged via cv2.addWeighted. 


 Engineering Observations: A clear boundary exists between the geometric and photometric phases. Warping acts strictly as a spatial transformation, altering coordinate grids to eliminate lens alignment drift and perspective disparities. Blending follows as a purely radiometric mixer, linearly interpolating pixel color intensities once the underlying layers are perfectly co-registered.  Severe underexposure caused a high keypoint dropout rate across low-contrast zones like hair and clothing, forcing ORB to cluster features heavily around high-gradient boundaries (eyes and background lights). While RANSAC successfully established a spatial consensus from these dense clusters, this skewed distribution optimizes alignment precision near the center of the frame while introducing minor sub-pixel alignment errors along the under-sampled margins.
