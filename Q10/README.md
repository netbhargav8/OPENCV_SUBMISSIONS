# Task 10 — Camera Calibration and Lens Undistortion

This project calibrates a phone/webcam camera using checkerboard photos, then uses the resulting camera matrix and distortion coefficients to undistort a normal scene.

## Files

```text
Q10/
├── task_10_camera_calibration_and_lens_undistortion.ipynb
├── calib_images/                 # Checkerboard photographs
├── ordinary_scene.jpg            # Straight-line scene for the final comparison
├── camera_calibration.npz        # Created after calibration
└── undistortion_before_after.jpg # Created after undistortion
```

`camera_calibration.npz` and `undistortion_before_after.jpg` are generated by the notebook.

## Requirements

Install the required packages in the Python environment used by Jupyter:

## Important checkerboard detail

The printed target is labelled **9×6 squares**. OpenCV expects the number of **internal corners**, not the number of squares. Therefore this notebook correctly uses:

```python
INNER_CORNERS = (8, 5)
```

Using `(9, 6)` makes corner detection fail for these images.

## How to run

1. Put the checkerboard photos in `calib_images/`.
2. Open `task_10_camera_calibration_and_lens_undistortion.ipynb` in Jupyter.
3. Select **Run All Cells**.
4. Read the detection log. It lists every accepted image and why rejected images were discarded.
5. Check the calibration output for `fx`, `fy`, `cx`, `cy`, RMS reprojection error, and mean point reprojection error.
6. Add `ordinary_scene.jpg` beside the notebook and run the final cell again.

The final cell saves `undistortion_before_after.jpg`, with the original image on the left and the undistorted result on the right.

## Taking the ordinary scene photo

Use the same phone/webcam as the calibration images. Photograph an ordinary scene with long straight lines near the frame edges, such as a door, window, bookshelf, tiled wall, or corridor.

The scene image can be at a smaller resolution, as long as it keeps the same aspect ratio as the calibration images. The notebook scales the camera matrix automatically. For example, the supplied calibration images are 3060×4080 and a 1200×1600 scene image is compatible because both use a 3:4 aspect ratio.

## Current image status

The supplied set contains 15 checkerboard photos. The notebook currently accepts 7 images (`img1`, `img2`, `img3`, `img4`, `img5`, `img8`, and `img9`) and discards 8. Most discards do not show the complete 8×5 grid reliably because of blur, glare, cropping, or extreme tilt; `img15` has a different image size.

Although OpenCV can calibrate with a small number of views, capture and accept **at least 12 diverse images** before submitting. Retake failed photos with these guidelines:

- Keep the full checkerboard in frame.
- Keep the board sharp and evenly lit.
- Use different distances, angles, and tilts.
- Move the board to different parts of the image frame.
- Keep the camera resolution and aspect ratio unchanged.
